# Kriztan Kay — Music Producer Portfolio

A responsive portfolio website for music producer and sound artist Kriztan Kay.

The project was built from a custom Figma design and translated into a fully responsive website using HTML, CSS and vanilla JavaScript.

## Live Website

https://www.kriztankay.com

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub
- GitHub Pages
- Formspree

## Features

- Fully responsive desktop, tablet and mobile layouts
- Sticky navigation
- Responsive hamburger menu
- Scroll progress indicator
- Interactive hero section
- Music filtering by category
- Horizontal music slider with Previous / Next navigation
- Responsive two-card mobile music carousel
- Music card hover interactions
- Individual external music links
- Parallax background effect
- Responsive About and Contact sections
- Functional contact form using Formspree
- SEO and Open Graph meta tags
- Custom hover states and micro-interactions

## Development Process

The website was developed section by section from a Figma reference.

The project was built on a separate `redesign-2026` Git branch before being tested, merged into `master`, and deployed through GitHub Pages.

During development I worked on:

- semantic HTML structure
- CSS Grid and Flexbox layouts
- responsive breakpoints
- JavaScript DOM manipulation
- event listeners
- filtering logic
- horizontal scrolling
- mobile navigation
- form integration
- Git branching, commits and merging

## What I Learned

This project helped me strengthen my understanding of responsive frontend development and translating visual designs into working interfaces.

I also gained practical experience with JavaScript interactions, Git workflows, deployment and debugging layouts across different screen sizes.
